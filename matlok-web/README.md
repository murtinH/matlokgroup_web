# matlok-web

Web skupiny **Matlok Group s.r.o.** — Astro + Sanity + Cloudflare Pages.

## Co je v repozitáři

| Složka / soubor | Co to je |
|---|---|
| `ZADANI.md` | Technické zadání — stack, routy, formulář, obsahový model, integrace API. **Začni tady.** |
| `prototyp/` | Statický HTML prototyp všech stránek. Vizuální předloha, ze které se staví komponenty. Nepatří do produkce. |
| `CLAUDE.md` | Konvence projektu — čte se automaticky v Claude Code. |

## Stav

Fáze 0 — prototyp hotový, implementace zatím nezačala.

## Jak pokračovat

```bash
npm install
npm run dev        # web na http://localhost:4321
npm run dev:studio # Sanity Studio
```

(Skripty vzniknou při scaffoldu — zatím repozitář obsahuje jen podklady.)
